# Project Setup Instructions

To run this project after cloning or pulling from Git, follow these steps:

1. Open a terminal and navigate to the project directory:
   
   cd Frontend/insightx

2. Install all dependencies:
   
   npm install

This will install all required packages as specified in package.json.

## Main Dependencies
- react
- react-dom
- typescript
- react-scripts
- three
- gsap
- ogl
- framer-motion
- lucide-react
- @testing-library/*
- @types/*
- web-vitals

No extra dependencies are needed beyond what is in package.json.

---
If you encounter any issues, ensure you are using Node.js v16 or later.
